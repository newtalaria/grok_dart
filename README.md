# grok_dart

Official-quality Dart client for the [xAI](https://x.ai) Grok API, by
[Talaria](https://www.newtalaria.com).

**This package is under development.** Version 0.0.1 is a placeholder that
reserves the name on [pub.dev](https://pub.dev). The client API is not
implemented yet and is not ready for use.

Repository: [github.com/newtalaria/grok_dart](https://github.com/newtalaria/grok_dart)
